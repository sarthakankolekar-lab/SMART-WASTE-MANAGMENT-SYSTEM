# 🗑️ Smart Waste Management System — PuneWaste

A smart, AI-driven waste management web application built for **Pune District**, India. It helps citizens locate nearby smart bins and allows municipal teams to manage collection routes efficiently using real-time IoT data.

## 📌 About the Website

**PuneWaste** is a single-page web application designed to give the data of all local dustbins by location and inform the municipal corporation authority to collect the waste from the dustbins. It features two main portals:

### 👤 Citizen Portal
- View a live interactive map of smart bins across Pune
- See bin fill levels in real-time (green / yellow / red status)
- Get turn-by-turn directions to the nearest bin
- Report overflowing bins directly from the app

### 🏛️ Municipal Team Portal
- Secure login for municipal staff
- Dashboard to monitor all bins across the city
- AI-optimized truck collection routes
- Fleet and sensor management tools

## ✨ Key Features

- 🗺️ **Real-time Map** — Leaflet.js powered interactive map with bin markers
- 🤖 **AI Route Optimization** — Smartest collection routes for municipal trucks
- 📡 **IoT Sensor Data** — Live fill-level tracking for every bin
- 🎬 **Interactive Demo** — Animated walkthrough showing how to use the website
- 🌙 **Dark Glassmorphism UI** — Premium dark-themed design with gold accents
- 📱 **Responsive Design** — Works on desktop and mobile

## 🛠️ Tech Stack
